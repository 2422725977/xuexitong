# 从零复现：环境、解壳、取证

本机实测环境（macOS arm64，Apple Silicon）：

| 组件 | 版本 / 路径 |
|---|---|
| Python | `/opt/anaconda3/bin/python3` 3.14.6（依赖 requests 2.34.2 / opencv 5.0.0） |
| Node | v26.12.1 |
| JDK | `/opt/homebrew/opt/openjdk@17/bin/java`（只在要跑 apktool/jadx 时用） |
| Android SDK | `/opt/homebrew/share/android-commandlinetools`（platform-tools + emulator + system-images） |
| AVD | `cx29` = API 29 **default**(userdebug) **arm64-v8a**，`-writable-system` 启动 |
| Frida | 17.26.3 + `frida-server`（`/data/local/tmp/fsd`） |
| droidasc | 0.1.2.post4（纯 Python，无 JVM，`/opt/anaconda3/bin/droidasc`） |

> 选型要点：**必须 arm64-v8a 系统镜像**（样本 `lib/` 只有 arm64-v8a，x86_64 加载不了 `libDexHelper.so`）；
> 必须 **default/google_apis（userdebug）** 而不是 google_play，否则 `adb root`/`remount` 用不了。

## 1. 加固样本的静态边界（为什么必须动态解壳）

- `classes.dex` 头声明 98,377,912 B，真实内容止于 ~24,728 B，里面只有 **17 个类**：
  12 个 `com.alibaba.android.arouter.routes.*` + 5 个 `com.secneo.apkwrapper.{AP,AW,CP,H,a}`；
- 其后 ~98 MB 是加密载荷：94×1 MB 分块的熵图呈 cipher(7.4–8.0)/compressed(5.4–6.5) 交替；
- 静态解壳失败证据：**2,570 个 zlib 头候选 inflate 成功 0**；10 个候选偏移 × 256 个单字节 XOR 均无 `dex\n035`；386 万字节尾部含 523,044 个唯一 16 字节块（近随机）；
- native 侧确认梆梆 VMP：`lib/arm64-v8a/libDexHelper.so` 含 `en_fun / g_func_map / dexflag / multidex_entry / JNI_OnLoad` 等 14 个 VMP 标记 + 624 个加密符号名；节头表被抹；壳还故意放了一个 x86 版 `libDexHelper-x86.so` 作干扰。

## 2. 动态解壳（内存 dump，实测可用）

核心：**在解密完成后、反调试点到来前把进程冻住，然后从 `/proc/<pid>/mem` 直读所有 rw 段。**

```bash
# ① AVD
avdmanager create avd -n cx29 -k "system-images;android-29;default;arm64-v8a" -d pixel
emulator -avd cx29 -no-snapshot -writable-system -no-audio -gpu swiftshader_indirect &
adb wait-for-device && adb root && adb remount
adb install -r 学习通.apk

# ② frida-server
adb push frida-server-17.x-android-arm64 /data/local/tmp/fsd && adb shell "chmod 755 /data/local/tmp/fsd"
adb shell "nohup /data/local/tmp/fsd &"

# ③ 启动并立刻冻结（解密在 Application.attachBaseContext 阶段完成，约 2.5 s）
adb shell "monkey -p com.chaoxing.mobile -c android.intent.category.LAUNCHER 1" &
sleep 2.5 && PID=$(adb shell pidof com.chaoxing.mobile) && adb shell "kill -STOP $PID"

# ④ dump 所有 rw 区（脚本用 64 位安全页号计算）
bash scripts/snap3.sh

# ⑤ 本机按 dex magic + adler32/SHA-1 校验切成 11 个真 dex
python3 scripts/extract_dex.py          # -> out/dexes/，并生成校验
python3 scripts/mk_apk.py               # 打成可被静态工具消费的 apk -> out/unpacked.apk

# ⑥ 静态查询（droidasc 只吃 apk/zip）
droidasc listclass out/unpacked.apk > out/dumped_all_classes.txt
python3 scripts/dex_strings.py          # -> out/dumped_strings.txt（388,486 唯一串）
```

产物校验：`evidence/dexes.sha256`（11 个 dex 的 sha256）。

## 3. Frida 用法（本仓库脚本）

```bash
# 抓签到链路（含 cookie 导出、enc 明文、扫码分发、人脸桥）
frida -U -f com.chaoxing.mobile -l scripts/frida_sign_hook.js --no-pause
# 人脸：伪造活体结果 / 指定注入图片
frida -U -f com.chaoxing.mobile -l scripts/frida_face_puppet.js --no-pause
# 反反调试（检测到 ptrace 会启动子进程，见脚本注释）
frida -U -f com.chaoxing.mobile -l scripts/anti_anti.js --no-pause
```
